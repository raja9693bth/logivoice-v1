# LogiVoice V1 — Inbound Logistics Voice Operations Portal

LogiVoice V1 is an enterprise-grade inbound voice AI dispatcher operations portal tailored for road freight, 3PLs, and full truckload (FTL) logistics operators. It handles real-time voice call auditing, deterministic pricing quotation, intent classification, lead qualification, operational ticket escalation, and post-call WhatsApp nurturing.

---

## Key Features

### 1. Operations Dashboard (`/admin`)
- **Restrained Bento Grid**: Real-time operational KPIs for daily calls, missed connections, roadside escalations, open booking requests, and qualified leads.
- **Urgent Operational Attention**: High-priority incident feed for immediate roadside assistance and breakdown triage.
- **Voice Operational SLA**: Telemetry tracking perceived latency (p50 target < 1.2s), tool execution success rate, and tenant isolation integrity.
- **Recent Inbound Calls Feed**: Operational log with instant call drawer inspection.

### 2. Operational Inbound Calls Audit (`/admin/calls` & `/admin/calls/[id]`)
- Comprehensive call log supporting multi-filter search (Customer, Phone, LR Tracking #, Intent, Outcome, Lead Temperature).
- **Dedicated Call Forensics (`/admin/calls/[id]`)**:
  - Executive Operational Summary.
  - Extracted Operational Facts (Origin, Destination, Weight Band, Vehicle Type, Material, Quoted Amount, Booking Ref).
  - Verbatim Turn-by-Turn Bilingual Audio Stream Transcript (Hinglish/Hindi/English) with timestamped speaker bubbles.
  - Operational Tool Events Timeline with formatted, contained JSON input/output payload visualization.
  - Customer profile identification and roadside escalation routing.
  - Post-call WhatsApp nurturing status and dispatch payload snippet.

### 3. Operations Requests & Tickets (`/admin/requests`)
- Booking requests, support tickets, and dispatcher callbacks generated by voice AI.
- Priority levels (URGENT, HIGH, NORMAL) and real-time dispatcher workflow stage updates (CONFIRMED, IN REVIEW, COMPLETED, REJECTED).
- Detailed operational payload drawer inspection.

### 4. Commercial Pipeline & Lead Nurturing (`/admin/leads`)
- Post-call commercial nurturing for freight quotation and booking opportunities.
- Deterministic rule-computed temperature scoring:
  - **HOT**: Immediate freight intent with complete route and vehicle requirements.
  - **WARM**: Commercial interest pending rate approval or decision.
  - **COLD**: General freight inquiry or informational call.
  - **REVIEW**: Ambiguous or high-value exception requiring human dispatcher assessment.

### 5. Approved Rate Cards & Pricing Matrix (`/admin/rate-cards`)
- Deterministic commercial rate matrix queried by voice AI during inbound quotation turns.
- Lane-by-lane configuration (Origin, Destination, Vehicle Category, Weight Band, Commercial Rate, Minimum Charge, Transit SLA).
- Full CRUD rate drawer and CSV bulk import preview modal.

### 6. Approved Operational Knowledge Base (`/admin/knowledge`)
- Grounded operational business policies, service hub coverage, and detention/waiting FAQs.
- Enforces the **6-Layer SSOT Runtime Architecture**: Voice models receive structured knowledge retrieved on-demand per caller intent rather than a monolithic prompt.

### 7. System & Tenant Configuration (`/admin/settings`)
- Tenant branding and legal identity settings.
- Bilingual Hinglish conversation persona, real-time interruption (barge-in), and language mirroring controls.
- Human escalation directory with verified routing numbers.
- Infrastructure telemetry for Retell AI voice gateway and Supabase PostgreSQL.

### 8. System Status & Forensic Audit Logs (`/admin/audit`)
- Complete audit trail of inbound webhooks, operational tool executions, follow-up dispatches, and security policies.
- Forensic JSON payload drawer viewer with formatted syntax highlighting and overflow containment.

## Design System & Theming

- **Minimalism & Restrained Bento**: Purpose-built for operational density, high legibility, and rapid dispatcher scanning.
- **Production Light / Dark Theme System**:
  - Centralized semantic token architecture built on Tailwind CSS v4.
  - Zero raw-inverted white: carefully balanced slate neutrals (`#f8fafc`, `#ffffff`, `#e2e8f0`, `#090d16`, `#0e1526`).
  - Accessible header theme toggle (`☀️ / 🌙`) with keyboard focus ring and accessible labels.
  - Anti-FOUC (Flash of Unstyled Content) initialization script in `<head>`.
  - Client-side persistence in `localStorage` with system media preference fallback.
- **Layout & Overflow Robustness**:
  - Fluid flex and grid layouts with `min-w-0` and `max-w-full` containment.
  - Pre/code blocks and JSON viewers engineered with `overflow-x-auto` and `break-all` wrapping.
  - Fully responsive across desktop (1440px+), standard laptops (1024px), tablets (768px), and mobile (375px) with slide-over mobile navigation drawer.

## Tech Stack

- **Framework**: [Next.js 16 (App Router)](https://nextjs.org/)
- **Core**: React 19, TypeScript
- **Styling**: Tailwind CSS v4 (`@tailwindcss/postcss`)

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Environment Variables
Copy `.env.example` to `.env.local` and configure credentials:
```bash
cp .env.example .env.local
```

### 3. Run Development Server
```bash
npm run dev -- -p 3005
```
Open [http://localhost:3005](http://localhost:3005) in your browser.

### 4. Build for Production
```bash
npm run build
npm start
```
